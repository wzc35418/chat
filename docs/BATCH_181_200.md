# 批次总结：R-310 … R-329（第 181–195 轮）

这一批的主线：**从“功能能跑”转向“坏了能自己说清楚”**。新增的不是新能力，而是**诊断能力**——一条命令拿到结构化结论，失败项自动翻译成建议，并且这些诊断本身也有自动断言。

## 一、新增能力（8 项）

| 能力 | 说明 | 验证方式 |
| --- | --- | --- |
| `Chat.exe --diagnose` | 无界面诊断：节点配置 → 服务启动 → 自检 → 会话；报告写 UTF-8 文件 | 实跑 + 报告文件 |
| `--diagnose --json` | 一行 JSON（endpoint/checks/conversations/result/allOk） | `tools/verify-diagnose.ps1` 自动断言 |
| 诊断建议 `DiagnoseHints` | 失败项 → 可执行建议；未知失败不给假建议 | `diagnoseHintsSmoke`（6 条断言，含 2 条反向） |
| 环境检查 `EnvironmentChecks` | 剪贴板 / 数据目录可写 / 磁盘余量 / 端口 TCP | `envChecksSmoke`（含不可达端口负例） |
| 「复制」按钮 | KeyPackage / 邀请包 / 提示行一键复制 | `clipboardSmoke`（含中文/换行往返） |
| 加好友闭环 | 邀请口令：预览 → 接受 → 联系人 | `inviteFlowSmoke`（A→B 真实往返） |
| 发送中乐观气泡 | `我 · 发送中…`，绝不把未确认画成已发送 | 编译 + 启动 + 截图 |
| 会话列表预览 | `21:10 我：正文前 24 字`；取不到退回 epoch 信息 | 截图 |
| 群详情增强 | 待处理提案明细 / 复制群 ID / **能力边界说明** | 编译 + 启动 |
| 对话框与按钮自检 | 空 `onDismissRequest` / 空 `onClick` 一律报错 | `check-ui-dialogs.cjs`（含负向样本） |
