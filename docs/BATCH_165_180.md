| # | Bug | 现象 | 根因 |

## 四、这一批我自己犯的错（8 条）

| # | 错误 | 教训 |
| --- | --- | --- |
| 1 | 用 `java -cp` 冒烟验证 `Chat.exe` | **两条启动路径不同**，包装产物必须用 exe 验证 |
| 2 | 把“空日志”当成产品卡住 | 先怀疑工具（`openssl s_client` 等 stdin） |
| 3 | 说“指纹在设置→传输安全里配”（那个入口不存在） | 不要承诺界面上没有的入口 |
| 4 | `Row` 里用 `HorizontalDivider` | 布局组件的“方向”必须对 |
| 5 | Gradle `JavaExec` 传 `-D` | **不转发**，要用 `-P` + `systemProperty`（踩了两次） |
| 6 | 用 `msg:out:` 当消息 id | 协议 id 格式由内核强制（`msg:1:<64 hex>`） |
| 7 | 假定“同步能把消息拉回来” | 自己的消息必须自己落库 |
| 8 | 假定“身份库和消息库可以共用一个文件” | 单写者 + 分表语义，不要混 |
