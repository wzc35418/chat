## 什么条件下可以改判 `complete`

按优先级，**缺一不可**（至少前两条）：

- [ ] **两台真机通过公网节点**完成：加好友 → 配对建群 → 双向发消息，并在 `docs/TWO_DEVICE_CHECKLIST.md` 的记录表里留下结果（含两端 epoch 一致）；
- [ ] 一次 **≥ 1 小时**的稳定运行记录（消息数、失败数、内存/磁盘曲线），或 ≥ 20 分钟并发（≥ 2 客户端）；
- [ ]（可选但建议）MSI 或等效安装器 + 开机自启，附带一次全新机器的安装验证；
- [ ]（可选）附件上传接线 + 一个真实文件跨机传输；加入已有群接口 + 一次真实加人。

上述前两条完成时，B 口径可上调到 ≈95%，并可考虑 `complete`；后两条属“生产级完善”，不阻塞交付但会写进交接清单。
