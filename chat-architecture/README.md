# 跨平台加密聊天软件：架构设计包

版本：0.1，日期：2026-10-18。状态：设计提案，尚未实现。

本设计将 Android、Linux、Windows、Kotlin 界面、自托管、P2P、端到端加密、桌面插件和群聊整合成一个分阶段方案。产品名称暂以 `chat` 代称。

## 阅读顺序

希望一次阅读或复制完整方案时，打开 [完整架构设计（单文件合并版）](完整架构设计.md)。它包含下列四份文档的全部正文；分文件版本便于在代码项目中分别维护。

1. [完整架构与项目目录](docs/ARCHITECTURE.md)：技术选择、模块边界、网络、身份、加密、群聊、插件、存储和部署。
2. [核心接口与协议草案](docs/CORE_INTERFACES.md)：Kotlin 应用接口、插件 SDK、协议模型和服务端接口。
3. [第一版 MVP 与验收标准](docs/MVP.md)：明确实现范围、阶段依赖和可以演示的完成条件。
4. [对话要点与设计决策](docs/CONVERSATION_NOTES.md)：保存需求来历、此前方案和本次收敛结果。这是整理稿，不是聊天逐字导出。

## 如何放进自己的项目

这份设计包已经保存在当前聊天工作文件夹的 `outputs/chat-architecture/` 中；同级 `chat-architecture.zip` 是完整压缩包。

- 已有项目：将本包 `docs/` 里的四份 Markdown 文件复制到项目的 `docs/design/`，即可作为设计资料随项目管理。
- 只想保留一份文件：复制 `完整架构设计.md` 即可。
- 尚未创建项目：可以先复制整个设计包到希望保存项目的位置，再按架构文档中的目录建立代码工程。
- 希望保留当前讨论上下文：一起保存 `CONVERSATION_NOTES.md`。需要逐字聊天记录时，应使用应用实际提供的复制或导出功能；本包不声称是原生聊天导出。
- 文档是普通 UTF-8 Markdown，使用编辑器即可阅读；Mermaid 图需要支持 Mermaid 的预览器，其他正文不依赖任何特殊工具。

架构文档中的项目树是建议的代码目录；本设计包只包含文档，没有生成可运行项目，也没有验证依赖编译或性能。

## 本版定案

客户端：Kotlin + Compose Multiplatform；协议内核与应用节点：Rust；设备连接：iroh；消息加密：MLS/OpenMLS（先过三端技术验证）；数据：SQLite；桌面扩展：配置包与可信 Kotlin 插件。

MVP 包含小群聊，默认采用协调节点确认的模式。节点无需解密聊天正文，但承担可用性和排序职责。自由 P2P 群、公开插件沙箱和多节点自动联邦不属于第一版。
